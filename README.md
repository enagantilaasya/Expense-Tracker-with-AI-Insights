# Backend Overview

This project is the backend structure of an Expense Tracker With AI Insights application developed using:

- Node.js
- Express.js
- MongoDB
- Mongoose

The backend provides APIs for:

- User authentication
- Transaction management
- Expense and income tracking
- AI insights and predictions
- Budget alerts and analytics

It also supports:

- JWT authentication
- Middleware protection
- Cookie handling
- AI-based predictions
- Secure REST APIs

# Frontend Overview

This project is the frontend of a MERN Stack Expense Tracker With AI Insights application developed using:

- React JS
- Vite
- Tailwind CSS
- React Router DOM
- Zustand
- Axios

The application provides:

- User Authentication
- Dashboard Analytics
- Expense & Income Tracking
- AI Insights and Predictions
- Budget Alerts
- Receipt Scanner
- Reports and Graph Analytics
- Protected Routes
- Responsive UI
